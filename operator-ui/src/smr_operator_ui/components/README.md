# components

운영 화면 여러 곳에서 재사용하는 PyQt6 위젯을 관리하는 폴더다. 화면 전체를 구성하기보다는 상태 표시, 수치 행, 검사 진행 시각화처럼 독립적으로 재사용할 수 있는 UI 단위를 둔다.

## 포함 파일

- `widgets.py`
  - `ConnectionBadge`: 장비 이름과 연결 상태를 표시한다.
  - `MetricRow`: 항목명과 실시간 값을 한 행으로 표시한다.
  - `SequenceStep`: 구간별 검사 순서와 현재 활성 단계를 표시한다.
- `orbit_view.py`
  - `OrbitView`: 검사 대상, 12개 원주 구간, 진행 상태, 로봇 위치를 `QPainter`로 직접 그린다.
  - 중앙 검사 대상을 터치하면 `target_clicked` 시그널을 발생시킨다.
- `__init__.py`
  - 화면에서 공통 위젯을 간결하게 가져올 수 있도록 공개 클래스를 내보낸다.

## 작성 규칙

- 두 개 이상의 화면에서 사용할 수 있는 위젯을 이 폴더에 둔다.
- 장비 통신이나 PostgreSQL 저장 로직을 직접 구현하지 않는다.
- 외부 동작 요청은 `pyqtSignal`로 전달한다.
- 상태값은 `state` 폴더의 모델을 전달받아 표시한다.
- 색상과 공통 스타일은 `styles` 폴더의 토큰과 QSS를 사용한다.
- 특정 화면에서만 사용하는 단순 위젯은 해당 `screens` 모듈에 둔다.
