# state

서비스와 UI 화면 사이에서 공유하는 애플리케이션 상태 모델을 관리하는 폴더다. 화면마다 같은 상태를 따로 보관하지 않도록 하나의 스냅샷 형태로 전달한다.

## 포함 파일

- `models.py`
  - `CyclePhase`: 검사 구간에서 반복되는 단계 열거형이다.
  - `ConnectionState`: 장비 연결 상태를 표준화한 열거형이다.
  - `EquipmentState`: 외부 장비 하나의 연결 상태와 최근 수신 시각을 가진다.
  - `CycleState`: 현재 구간, 완료 구간, 단계, 속도, 리프트, TCP 좌표, 안전 상태 등을 가진다.
  - `AppSnapshot`: 검사와 PLC·AMR·Cobot·UT 상태를 하나로 묶는다.
  - `initial_snapshot()`: 프로그램 시작 전 사용할 안전한 초기 상태를 만든다.
- `__init__.py`
  - 화면과 서비스에서 사용할 상태 모델을 공개한다.

## 상태 전달 원칙

- 상태 모델은 `@dataclass(frozen=True)`를 사용해 불변 객체로 관리한다.
- 값을 변경할 때 기존 객체를 직접 수정하지 않고 `dataclasses.replace()`로 새 스냅샷을 만든다.
- 서비스는 완성된 `AppSnapshot`을 시그널로 전달한다.
- 화면은 전달받은 스냅샷을 표시할 뿐 별도의 진실 원천을 만들지 않는다.
- 실제 장비 연동 시 마지막 수신 시각과 데이터 유효성을 함께 관리한다.
