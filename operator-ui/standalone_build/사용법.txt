SMR RCS 단독판 (로봇 + TPAC) 사용법
=====================================

ERUT · 차량(AGV) · PLC 없이 협동로봇(Elite CS612)과 TPAC 만으로 검사하는 버전입니다.
작업 설정(대상 지름 · 작업 영역 · 스캐너 높이 · 겹침)을 RCS 에서 하고 [검사 시작]을 누르면
로봇이 스캔하고, TPAC 은 이 PC 의 Modbus 서버(포트 502)에서 스캔 좌표를 읽어 갑니다.


1. 실행
-------
  SMR-RCS-Standalone.exe 를 두 번 누르면 됩니다. 설치는 필요 없습니다.
  (실행 파일 하나에 다 들어 있어 처음 뜨기까지 5~10 초 걸립니다.)

  처음 실행할 때 나올 수 있는 창
  - "Windows의 PC 보호" (SmartScreen) → [추가 정보] → [실행]
  - "Windows 보안 경고" (방화벽) → [허용]
      TPAC 이 이 PC 의 포트 502 에 접속해야 하므로 반드시 허용하세요.
      TPAC 이 연결된 네트워크 종류(개인/공용)에 체크되어 있어야 합니다.


2. 처음 한 번 — 로봇 연결
-------------------------
  설정(톱니) → [연결 설정]
    협동로봇 IP   : 로봇 IP (예: 192.168.227.134)
    Modbus 포트   : 502
  [저장] 하면 로봇에 자동으로 붙습니다. 위쪽 Cobot 표시가 초록이면 연결된 것입니다.
  로봇이 붙으면 TPAC 서버도 자동으로 켜집니다(위쪽 TPAC 표시).

  ※ 펜던트에서 로봇 태스크(dusan_task_v5)가 실행 중이어야 합니다.
  ※ 이 PC 는 로봇과 같은 네트워크, TPAC 과 같은 네트워크에 모두 있어야 합니다.


3. 작업 설정
------------
  메인 화면
    - 원(검사 대상) 그림을 누르면 → 바깥 지름[m], 높이[m]
    - 작업 영역(사각형) 그림을 누르면 → 너비[mm], 높이[mm],
        스캐너 높이[mm] (= 한 번 스캔할 때의 세로 높이), 최소 겹침[mm]
  설정 → [Cobot 설정] : 태스크 선택, 속도 비율, 장착 EOAT(5축 · 8축) 선택
    태스크 선택에서 dusan_v5_tpac_exhibition(전시판)을 고르면
      시편을 **바닥에 눕혀 놓은** 배치로 돕니다(아래 6항). 3점 위치를 돈 뒤 원점에서
      기다리지 않고, 좌우 비비기 없이 바로 스캔합니다(논센서).
      고르는 즉시 로봇에 그 태스크를 불러옵니다. 다음 실행 때도 그대로 남습니다.
  설정 → [Cobot 조그 / 위치 저장] : 홈 위치 · 스캔 대기 위치 저장


4. 검사
-------
  [검사 시작] → 로봇이 시작 위치로 가서 3점 접촉 → 적심 → 줄마다 스캔 → 물러섬 → 홈
  [일시정지] / [재개], 비상 시에는 펜던트 비상정지를 쓰세요.
  차량 · 리프트 · 아웃트리거 단계는 이 버전에서 모두 건너뜁니다(구역 1개만 검사).


5. TPAC 연결
------------
  TPAC 쪽 Modbus 접속 대상 : 이 PC 의 IP, 포트 502
  설정 → [TPAC 설정 / TCP 인코딩] 화면에서 주소 · 값 · DO 신호를 확인할 수 있습니다(아래는 기본값).
    - 스캔 좌표(TCP) : 400 번부터
    - 평면 위치 420, 주행 거리 430, C-scan 431
    - DO 코일 16~18 (스캔 플래그 · 방향)
  주소나 형식을 바꾸려면 같은 화면에서 바꾼 뒤 서버를 다시 켜면 됩니다.


6. 로봇 태스크 (전시판 — 시편을 바닥에 눕힘)
--------------------------------------------
  넣기: robot_task\dusan_v5 폴더 안의 것(dusan_v5_tpac_exhibition.task, scripts_tpac_exhibition,
        scripts_nosensor)을 로봇 컨트롤러의 Dusan/dusan_v5 폴더에 그대로 넣으세요.
        scripts_nosensor 에는 전시판이 함께 쓰는 세 파일만 들어 있습니다(같은 이름이면 덮어써도 됨).

  배치: 곡면 시편을 **볼록면이 위로** 바닥에 놓고, 곡면의 축(곧은 방향)이 로봇 **앞뒤
        (베이스 X)** 가 되게 둡니다. 호는 좌우(베이스 Y)로 그리고, 줄은 로봇에서
        **멀어지는 쪽(+X)** 으로 작업 영역 「높이」만큼 나아갑니다.

  티칭 (Cobot 조그 / 위치 저장)
    - 시작 포즈: 프로브를 판 꼭대기 선의 **첫 줄(로봇에 가장 가까운 줄) 가운데**에
      아래로 붙인 자세. 툴 X 가 좌우(호 방향), 툴 Y 가 앞뒤(줄 방향)가 되게 —
      8축 EOAT 는 세로 커버(167.5)가 앞뒤로 오도록 놓습니다.
    - 스캔 대기 위치: 판 **위쪽으로 충분히 높은** 자리. 작업이 끝나면 판에서 위로
      떨어진 뒤 대기 위치 높이까지 곧게 올라가고, 그 높이에서 앞뒤(X)만 맞춘 다음
      대기 위치 -> 홈으로 갑니다.
    - 너비(호 길이)는 세운 벽과 같은 제한(좌우 끝 사이 현 700 mm 이하)을 따릅니다.

  TPAC 좌표: 세운 벽 때와 뜻이 같습니다 — Y = 호를 따라 훑는 거리 쪽, Z = 줄 진행(+X).
             TPAC 설정은 바꾸지 않아도 됩니다.


7. 파일 위치
------------
  설정 · 저장한 위치 : 실행 파일 옆 「SMR-RCS-설정」 폴더 (처음 실행할 때 생깁니다)
                       settings.json(연결 · 태스크 · 작업 설정), robot_config(저장한 위치)
  실행 기록(로그)    : SMR-RCS-설정\logs\rcs_standalone.log
  검사 데이터        : D:\SMR\Data  (D 드라이브가 없으면 사용자 폴더\SMR\Data)
                       설정 → [시스템 설정] → 데이터 저장 위치에서 바꿀 수 있습니다.
  실행 파일과 「SMR-RCS-설정」 폴더를 **함께** 옮기면 설정도 따라갑니다(다른 PC 로 복사해도 됨).
  예전 판이 %APPDATA%\SMR-RCS 에 저장한 설정이 있으면 처음 실행할 때 한 번 가져옵니다.
  실행 파일 폴더에 쓸 수 없는 곳(Program Files 등)이면 %APPDATA%\SMR-RCS 에 저장합니다.


8. 문제가 생기면
----------------
  - Cobot 이 빨간색 : 로봇 IP, 랜선, 로봇 전원, 펜던트 원격 모드 확인
  - TPAC 설정 화면의 '외부에 제공'이 「시작 실패 — 포트 502 사용 중」:
      이 PC 의 다른 프로그램이 502 를 잡고 있습니다. 명령 프롬프트에서
          netstat -ano | findstr :502
      로 확인하세요. WSL(리눅스 RCS)로 넘기는 포트프록시(svchost)가 남아 있으면
      관리자 PowerShell 에서 지운 뒤 [서버 시작]을 누르면 됩니다.
          netsh interface portproxy delete v4tov4 listenport=502 listenaddress=0.0.0.0
      (리눅스 RCS 로 다시 쓰려면 같은 창에서
          netsh interface portproxy add v4tov4 listenport=502 listenaddress=0.0.0.0 connectport=502 connectaddress=<WSL IP>)
  - TPAC 이 안 붙음 : 방화벽에서 SMR-RCS-Standalone 허용 여부 확인
                     (Windows 보안 → 방화벽 → 앱 허용), 같은 PC 에서 다른 프로그램이
                     포트 502 를 쓰고 있지 않은지 확인
  - 위 로그 파일을 보내 주시면 원인을 찾을 수 있습니다.


9. 다른 PC 에서 쓰기
--------------------
  이 폴더(TPAC지원)를 통째로 복사하면 됩니다. 설치는 필요 없습니다.
    SMR-RCS-Standalone.exe   실행 파일 — Python · Qt · 프로그램 · 레지스터 주소표 · 글꼴이
                             모두 들어 있어 Python 이 없는 PC 에서도 그대로 돕니다(Windows 10/11 64bit).
    SMR-RCS-설정\            설정 · 저장한 위치 · 로그 (같이 복사하면 설정도 따라감)
    robot_task\              로봇 펜던트에 올리는 전시판 태스크
    source\                  exe 를 만든 소스 코드 전체 + 다시 만드는 방법(source\README.txt)
  새 PC 에서 처음 켤 때 SmartScreen · 방화벽 창이 다시 뜰 수 있습니다(1항).
  고쳐서 다시 만들 때만 source 폴더가 필요합니다 — source\README.txt 를 보세요.
