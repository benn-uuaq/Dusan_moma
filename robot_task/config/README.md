# robot_task/config

운영 UI가 저장하는 로봇 기준 위치를 두는 폴더다.

## `reference_poses.json`

`Cobot 조그 / 위치 저장` 화면에서 `홈 위치 저장` 또는 `시작 포즈 저장`을 누르면
UI가 이 파일을 갱신하고, 같은 값을 Modbus 레지스터에도 쓴다.

| 항목 | 내용 | 레지스터 |
| --- | --- | --- |
| `home_joint` | 홈 관절값 6개 [mrad] | 310~315 |
| `start_pose` | 시작 포즈 [X, Y, Z, Rx, Ry, Rz] (길이 mm, 회전 mrad) | 316~321 |

**레지스터는 전원을 내리면 사라지므로 이 파일이 원본이다.**

UI는 `robot/status/connected`가 참이 될 때마다 이 파일의 값과 Cobot 설정의
속도(작업 속도, 속도 비율)를 레지스터에 **자동으로 다시 쓴다.** 로봇을 껐다
켜거나 연결이 끊겼다 붙어도 태스크가 같은 기준 위치와 속도로 동작한다.
복원한 항목은 Cobot 수동 제어 화면 안내 문구에 나온다.

저장 위치는 `SMR_ROBOT_CONFIG_DIR` 환경 변수로 바꿀 수 있다.

태스크는 레지스터 308(`pose_src`)이 1일 때만 이 값을 쓴다. 0이면 펜던트
변수값(`Home_joint`, `start_pose`)을 그대로 쓴다.
