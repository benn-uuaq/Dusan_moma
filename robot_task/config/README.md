# robot_task/config

운영 UI가 저장하는 로봇 기준 위치를 두는 폴더다.

## `reference_poses.json`

`Cobot 조그 / 위치 저장` 화면에서 `홈 위치 저장`, `스캔 대기 위치 저장`, `시작 포즈 저장`을
누르면 UI가 이 파일을 갱신하고, 같은 값을 Modbus 레지스터에도 쓴다.

| 항목 | 내용 | 레지스터 (플래그) |
| --- | --- | --- |
| `home_joint` | 홈(접힌 자세) 관절값 6개 [mrad] | 322~327 (328 = 1) |
| `standby_joint` | 스캔 대기 위치 관절값 6개 [mrad] — 2026-10-16 전의 「홈」 | 310~315 (308 = 1) |
| `start_pose` | 시작 포즈 [X, Y, Z, Rx, Ry, Rz] (길이 mm, 회전 mrad) | 316~321 (308 = 1) |

로봇은 홈과 작업 자리 사이를 **언제나 스캔 대기 위치를 거쳐** 오간다
(홈 → movej 대기 위치 → 시작 위치 / 스캔 끝 → 물러나고 상승 → movej 대기 위치 → movej 홈).
RCS 의 「로봇 홈」 명령도 같은 순서다.

형식 판(`_layout`)이 없는 옛 파일의 `home_joint` 는 그때의 홈 = 지금의 스캔 대기
위치라, UI 가 처음 읽을 때 `standby_joint` 로 옮겨 저장한다. 홈은 새로 저장한다.

**레지스터는 전원을 내리면 사라지므로 이 파일이 원본이다.**

UI는 `robot/status/connected`가 참이 될 때마다 이 파일의 값과 Cobot 설정의
속도(작업 속도, 속도 비율)를 레지스터에 **자동으로 다시 쓴다.** 로봇을 껐다
켜거나 연결이 끊겼다 붙어도 태스크가 같은 기준 위치와 속도로 동작한다.
복원한 항목은 Cobot 수동 제어 화면 안내 문구에 나온다.

저장 위치는 `SMR_ROBOT_CONFIG_DIR` 환경 변수로 바꿀 수 있다.

태스크는 플래그가 1이고 그 칸이 비어 있지 않을(전부 0이 아닐) 때만 이 값을 쓴다.
아니면 펜던트 변수값(`Home_joint`, `Standby_joint`, `gripper_target_pose`)을 그대로 쓴다.
