# AMR 수동 이동, 자동 원주 검사, 아웃트리거 수평 보정

## 운용 개념

AMR은 검사 대상 위치까지 리모컨으로 수동 이동한다. 목적지 도착 후에는 소형원자로 또는 검사 대상 구조물을 기준으로 자동으로 원주 방향 이동을 수행하며, 협동로봇과 초음파 검사기를 이용해 비파괴 검사를 진행한다.

협동로봇이 초음파 검사를 수행하는 동안 AMR 본체는 아웃트리거로 고정되어야 한다. 본체 수평 상태는 IMU 센서로 확인하고, 아웃트리거를 이용해 수평을 보정한다.

구매사양서 기준으로 AMR은 실외용 4륜 구동 구조, 바퀴 직경 200 mm 이상, 라이다 또는 근접 센서 기반 접근 감지, 별도 리모컨 수동 운전, 이동형 충전장비, 크레인 이동용 Eye Bolt를 고려한다.

## 기본 동작 흐름

1. 작업자가 리모컨으로 AMR을 검사 시작 위치 근처까지 수동 이동한다.
2. AMR이 소형원자로 또는 기준 구조물의 상대 위치를 확인한다.
3. 검사 시작 전 아웃트리거를 전개한다.
4. IMU 센서로 본체의 roll, pitch 값을 확인한다.
5. 아웃트리거 높이를 조정하여 본체 수평을 보정한다.
6. 수평 상태가 허용 범위에 들어오면 협동로봇 검사를 허가한다.
7. 협동로봇이 초음파 프로브를 접촉시키고 검사 데이터를 취득한다.
8. 한 검사 구간이 완료되면 로봇을 안전 위치로 후퇴시킨다.
9. 아웃트리거를 회수하거나 이동 가능 상태로 전환한다.
10. AMR이 소형원자로 기준으로 다음 검사 위치까지 자동 원주 이동한다.
11. 다음 위치에서 수평 보정과 검사를 반복한다.

## 상태 정의

| 상태 | 설명 |
| --- | --- |
| ManualMove | 작업자가 리모컨으로 AMR을 목적지까지 수동 이동 |
| ReferenceDetect | 소형원자로 또는 검사 기준 위치 확인 |
| OutriggerDeploy | 아웃트리거 전개 |
| LevelCheck | IMU 기반 본체 수평 확인 |
| LevelAdjust | 아웃트리거 높이 조정으로 수평 보정 |
| InspectionReady | 검사 가능 상태 |
| RobotInspection | 협동로봇 기반 초음파 검사 수행 |
| RobotRetract | 협동로봇 안전 위치 후퇴 |
| OutriggerRetract | 아웃트리거 회수 또는 이동 가능 상태 전환 |
| AutoIndexMove | 다음 검사 위치로 자동 원주 이동 |

## 구매사양서 기반 AMR 확인 항목

| 항목 | 요구 내용 | 확인 방법 |
| --- | --- | --- |
| 구동 방식 | 실외용 4륜 구동 | 제조사 사양서, 현장 주행 테스트 |
| 바퀴 | 직경 200 mm 이상, 고무 재질 | 도면 및 실측 |
| 자동 이동 | 검사 대상 곡률을 따라 지정 각도/위치 자동 이동 | 원주 이동 시나리오 테스트 |
| 이격 거리 | 검사 대상과의 이격 거리 유지 | 센서 로그, 위치 오차 측정 |
| 접근 감지 | 설정 거리 이내 사물 접근 시 작동 일시정지 | 라이다/근접 센서 오류 주입 테스트 |
| 안정화 | 아웃트리거 고정 및 수평 조정 | IMU roll/pitch 로그 |
| 원격 조작 | 별도 리모컨 수동 운전 가능 | 수동/자동 모드 전환 테스트 |
| 충전 | 검사 중/후 충전 가능 이동형 충전장비 2개 | 충전 시나리오 확인 |
| 리프팅 | 크레인 이동용 Eye Bolt 적용 | 무게중심 및 인양 안전 검토 |

## 수평 보정 조건

| 항목 | 설명 | 비고 |
| --- | --- | --- |
| roll | AMR 좌우 기울기 | IMU 측정 |
| pitch | AMR 전후 기울기 | IMU 측정 |
| 허용 기울기 | 검사 허가 가능한 최대 기울기 | 장비 사양 확정 후 수치 입력 |
| 안정화 시간 | 보정 후 값이 안정될 때까지 대기하는 시간 | 진동 영향 고려 |
| 재보정 횟수 | 자동 보정 재시도 한계 | 초과 시 작업자 확인 |

## 인터락 조건

- 아웃트리거가 전개되지 않으면 협동로봇 검사를 시작하지 않는다.
- IMU 수평 값이 허용 범위를 벗어나면 협동로봇 검사를 시작하지 않는다.
- 협동로봇 검사 중에는 AMR 주행 명령을 차단한다.
- 협동로봇 검사 중에는 아웃트리거 회수 명령을 차단한다.
- AMR 자동 원주 이동 전에는 협동로봇이 안전 위치에 있어야 한다.
- AMR 자동 원주 이동 전에는 프로브가 검사 대상에서 분리되어야 한다.
- 아웃트리거 이상, IMU 이상, 본체 진동 과다 발생 시 검사를 중지한다.

## 확인 필요 사항

- 소형원자로 기준 위치 인식 방식: 라이다, 비전, 마커, 수동 기준점 중 선택
- 원주 자동 이동 경로 생성 방식
- 검사 구간별 AMR 정지 위치 오차 허용치
- IMU 센서 모델과 정확도
- 아웃트리거 개수, 배치, 스트로크, 제어 방식
- 협동로봇 검사 중 허용 가능한 본체 진동 기준
- 수평 보정 허용 roll/pitch 값
- 라이다/근접 센서 접근 감지 거리
- 원주 이동 각도 및 위치 오차 허용치
- 이동형 충전장비 사양 및 운용 방식
- Eye Bolt 위치와 인양 무게중심 검토 결과
