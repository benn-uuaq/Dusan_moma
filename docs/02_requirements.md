# 요구사항 정의

## 기능 요구사항

|ID|요구사항|우선순위|상태|
|-|-|-|-|
|FR-001|AMR은 작업자가 리모컨으로 검사 목적지까지 수동 이동할 수 있어야 한다.|높음|초안|
|FR-002|AMR은 목적지 도착 후 소형원자로 또는 기준 구조물을 기준으로 자동 원주 이동할 수 있어야 한다.|높음|초안|
|FR-003|AMR은 협동로봇 검사 중 아웃트리거로 본체를 고정할 수 있어야 한다.|높음|초안|
|FR-004|시스템은 IMU 센서로 AMR 본체의 roll, pitch를 확인할 수 있어야 한다.|높음|초안|
|FR-005|시스템은 IMU 값을 기준으로 아웃트리거를 제어하여 본체 수평을 보정할 수 있어야 한다.|높음|초안|
|FR-006|리프트는 협동로봇 작업 높이를 검사 대상에 맞게 조정할 수 있어야 한다.|높음|초안|
|FR-007|협동로봇은 초음파 프로브를 지정 경로로 이동시킬 수 있어야 한다.|높음|초안|
|FR-008|초음파 검사기는 검사 데이터를 파일로 저장할 수 있어야 한다.|높음|초안|
|FR-009|검사 시작, 중지, 재시작, 비상정지 절차를 제공해야 한다.|높음|초안|
|FR-010|검사 조건, 장비 상태, 데이터 파일명을 작업 기록과 연결해야 한다.|높음|초안|
|FR-011|협동로봇은 주사속도와 진행속도를 독립 조절할 수 있어야 하며 최대 주사속도 150 mm/s 이상을 지원해야 한다.|높음|구매사양서 반영|
|FR-012|협동로봇 시스템은 IP65 보호 등급을 만족해야 한다.|높음|구매사양서 반영|
|FR-013|AMR은 검사 대상 곡률을 따라 지정 각도와 위치로 자동 이동하고 이격 거리를 유지할 수 있어야 한다.|높음|구매사양서 반영|
|FR-014|AMR은 라이다 또는 근접 센서를 통해 설정 거리 이내 사물 접근 시 작동을 일시정지해야 한다.|높음|구매사양서 반영|
|FR-015|리프트는 수직 이동량을 실시간 측정하고 위치 데이터를 제공해야 한다.|높음|구매사양서 반영|
|FR-016|UT 기준 초과 신호 발생 시 마킹 시스템 트리거 신호를 출력할 수 있어야 한다.|중간|구매사양서 반영|
|FR-017|이상 동작 또는 충돌 위험 감지 시 알람 및 작동 일시정지 신호를 출력해야 한다.|높음|구매사양서 반영|

## 인터락 요구사항

|ID|요구사항|우선순위|상태|
|-|-|-|-|
|IL-001|아웃트리거가 전개되지 않으면 협동로봇 검사를 시작하지 않아야 한다.|높음|초안|
|IL-002|IMU 수평 값이 허용 범위를 벗어나면 협동로봇 검사를 시작하지 않아야 한다.|높음|초안|
|IL-003|협동로봇 검사 중에는 AMR 주행 명령을 차단해야 한다.|높음|초안|
|IL-004|협동로봇 검사 중에는 아웃트리거 회수 명령을 차단해야 한다.|높음|초안|
|IL-005|AMR 자동 원주 이동 전 협동로봇은 안전 위치에 있어야 한다.|높음|초안|
|IL-006|AMR 자동 원주 이동 전 초음파 프로브는 검사 대상에서 분리되어야 한다.|높음|초안|
|IL-007|라이다 또는 근접 센서가 설정 거리 이내 접근 물체를 감지하면 AMR 및 로봇 동작을 일시정지해야 한다.|높음|구매사양서 반영|
|IL-008|이상 동작 또는 충돌 위험 알람 발생 시 검사 시퀀스는 안전 정지 상태로 전환해야 한다.|높음|구매사양서 반영|

## 비기능 요구사항

|ID|요구사항|우선순위|상태|
|-|-|-|-|
|NFR-001|검사 결과는 추적 가능한 형식으로 저장되어야 한다.|높음|초안|
|NFR-002|제어 프로그램은 오류 발생 시 안전 상태로 전환해야 한다.|높음|초안|
|NFR-003|운영자는 검사 진행 상태, 아웃트리거 상태, IMU 수평 상태를 직관적으로 확인할 수 있어야 한다.|중간|초안|
|NFR-004|주요 설정값은 변경 이력 관리가 가능해야 한다.|중간|초안|
|NFR-005|시스템은 현장 네트워크 단절 상황을 고려해야 한다.|중간|초안|
|NFR-006|검사 구간별 AMR 정지 위치와 수평 보정 결과를 로그로 남겨야 한다.|높음|초안|

## 인터페이스 요구사항

|대상|주요 인터페이스|검토 사항|
|-|-|-|
|AMR|수동 이동 상태, 자동 원주 이동 명령, 현재 위치, 비상정지|제조사 API, 수동/자동 모드 전환|
|리프트|높이 명령, 현재 높이, 리미트 상태|정밀도, 반복정밀도, 안전 인터락|
|아웃트리거|전개/회수, 높이 조정, 접지 상태|스트로크, 하중, 제어 방식|
|IMU|roll, pitch, yaw, 진동 상태|정확도, 필터링, 안정화 시간|
|협동로봇|경로 명령, TCP 설정, 힘/토크 상태|로봇 SDK, 안전 영역|
|초음파 검사기|검사 시작/정지, 데이터 저장, 설정값 조회|SDK, 파일 포맷, 트리거 방식|
|ERUT UT 시스템|절대좌표 데이터 수신, 엔코더 동기화, 기준 초과 신호|통신 프로토콜(MQTT), 좌표 포맷, 시간 동기화|
|마킹 시스템|Paint Spray 등 트리거 출력|트리거 전압, 지연시간, 안전 조건|
|운영 UI|검사 계획 선택, 실행 상태, 알람 표시|사용자 권한, 로그 저장|

## 미정 사항

* AMR 모델 및 제어 API
* 리모컨 수동 이동 방식과 자동 모드 전환 방식
* 소형원자로 기준 위치 인식 방식
* 원주 자동 이동 경로 생성 방식
* 협동로봇 제조사와 모델
* 초음파 검사기 모델, 데이터 포맷, 외부 제어 가능 범위
* 검사 대상 형상 및 검사 위치 기준
* 필요한 검사 속도, 분해능, 허용 오차
* IMU 허용 roll/pitch 기준
* 아웃트리거 개수, 배치, 스트로크, 접지 확인 방식
* ERUT UT 시스템 통신 프로토콜 및 절대좌표 데이터 포맷
* 마킹 시스템 트리거 입출력 사양
* 안전 펜스 및 접근 센서 구성 방식
* 안전 인증 범위와 발주사 수정 협의 문구
