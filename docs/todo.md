# 할 일 목록

## 즉시 확인

- [ ] 이로운 솔루션에 UT 시스템 구성 문의 전달
- [ ] 스캐너 전원 사양, 도면, 입출력 사양, 필요 스펙 회신 확인
- [ ] 펌프 모델명, 전원 사양, 입출력 사양, 필요 압력 회신 확인
- [ ] 물탱크 용량 및 분사기 모델명 회신 확인
- [ ] AMR 모델, 제조사, 제어 API 확인
- [ ] AMR 리모컨 수동 이동 방식 확인
- [ ] AMR 수동/자동 모드 전환 조건 확인
- [ ] 소형원자로 기준 위치 인식 방식 결정
- [ ] 자동 원주 이동 경로 생성 방식 검토
- [ ] 리프트 사양 확인: 가반하중, 높이 범위, 반복정밀도
- [ ] 아웃트리거 사양 확인: 개수, 배치, 스트로크, 하중, 접지 감지 방식
- [ ] IMU 센서 사양 확인: roll/pitch 정확도, 샘플링, 필터링 방식
- [ ] 협동로봇 모델, 제어 SDK, 안전 기능 확인
- [ ] 초음파 검사기 모델, 외부 제어 가능 여부, 데이터 포맷 확인
- [ ] 검사 대상 형상, 검사 위치, 접근 제약 확인
- [ ] 필요한 검사 속도, 분해능, 허용 오차 정리
- [ ] 검사 허용 수평 기준값 정의
- [ ] 협동로봇 최대 주사속도 150 mm/s 이상 만족 여부 확인
- [ ] 협동로봇 IP65 보호 등급 인증 자료 확인
- [ ] AGV 실외용 4륜 구동, 바퀴 직경 200 mm 이상, 고무 재질 조건 확인
- [ ] 라이다/근접 센서 접근 감지 및 일시정지 로직 확인
- [ ] 엔코더 기반 3D 절대좌표 동기화 방식 확정
- [ ] ERUT UT 시스템 통신 프로토콜 사전 협의
- [ ] 마킹 시스템 트리거 출력 사양 확인
- [ ] 안전 인증 범위 및 공급자 취득 계획 확인
