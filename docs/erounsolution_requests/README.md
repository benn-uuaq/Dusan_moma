# 이로운 솔루션 요청사항 관리

## 문서 목적

이 문서는 프로젝트 주관사인 이로운 솔루션의 요청사항, 결정사항, 확인 필요 사항을 추적하기 위한 관리 문서이다. 구두 논의, 회의, 메신저, 문서 검토 과정에서 나온 요청을 이 문서에 먼저 기록하고, 확정된 내용은 요구사항 정의서, 시스템 아키텍처, 검사 절차서, 개발 계획 등에 반영한다.

## 주관사 정보

| 항목 | 내용 |
| --- | --- |
| 주관사 | 이로운 솔루션 |
| 프로젝트 | 소형 원자로 비파괴 검사 자동화 프로젝트 |
| 주요 관심 영역 | AMR 운용, 협동로봇 검사, 초음파 검사, 안전성, 현장 운용성 |
| 요청사항 관리 위치 | `docs/erounsolution_requests/` |

## 요청사항 처리 흐름

1. 요청사항을 접수한다.
2. 요청 ID를 부여한다.
3. 요청 배경, 기대 결과, 관련 장비 또는 문서를 기록한다.
4. 우선순위와 상태를 정한다.
5. 기술 검토가 필요한 항목은 확인 필요 사항으로 분리한다.
6. 확정된 요청은 관련 문서와 개발 작업에 반영한다.
7. 반영 결과와 검증 방법을 기록한다.

## 문서 반영 원칙

- 주관사 요청사항은 먼저 이 문서에 기록한다.
- 확정된 요청만 요구사항 정의서와 개발 계획에 반영한다.
- 안전, 검사 품질, 데이터 추적성에 영향을 주는 요청은 별도 리스크 검토를 수행한다.
- 요청사항이 기존 요구사항과 충돌할 경우 변경 사유와 결정자를 기록한다.
- 프로그램 구현으로 이어지는 요청은 작업 로그와 TODO에도 연결한다.
