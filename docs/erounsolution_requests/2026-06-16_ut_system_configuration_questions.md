# 이로운 솔루션 측 문의 사항: UT 시스템 구성

## 문의 목적

SMR 비파괴 검사 자동화 시스템 설계를 위해 UT 시스템 구성품의 모델명, 전원 사양, 입출력 사양, 통신 방식, 필요 스펙을 확인한다.

| 구분 | 문의 내용 | 비고 |
| --- | --- | --- |
| UT 시스템 구성 | 전체 UT 시스템 구성 범위 | 스캐너, 소프트웨어, 무선 통신, 펌프, 물탱크, 분사기, 기타 구성품 포함 여부 확인 |

## 확인 요청 문안

이로운 솔루션 측에 아래 내용을 확인 요청드립니다.

1. UT 시스템 전체 구성품 목록을 공유 부탁드립니다.
2. 스캐너의 전원 사양, 도면, 입출력 사양, 필요 스펙을 공유 부탁드립니다.
3. UT 관련 소프트웨어 구성, 운영 방식, SDK/API 제공 여부, 데이터 저장 포맷을 확인 부탁드립니다.
4. 무선 통신은 5G 또는 6G가 필수인지, Wi-Fi 또는 유선 이더넷 사용이 가능한지 확인 부탁드립니다.
5. 펌프의 모델명, 전원 사양, 입출력 사양, 필요 압력을 공유 부탁드립니다.
6. 물탱크 용량과 설치 제약 조건을 확인 부탁드립니다.
7. 분사기 모델명 및 노즐 사양을 공유 부탁드립니다.
8. 기타 필요한 구성품과 각 구성품의 전원 사양을 공유 부탁드립니다.
