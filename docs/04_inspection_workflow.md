# 검사 운영 절차

## 검사 전 준비

1. 검사 대상, 위치, 검사 범위를 확인한다.
2. AMR 배터리와 리모컨 수동 이동 가능 상태를 확인한다.
3. AMR 자동 원주 이동 기준점 또는 기준 구조물 인식 상태를 확인한다.
4. 리프트 동작 범위와 홈 위치를 확인한다.
5. 아웃트리거 전개/회수, 접지 상태, 높이 조정 가능 여부를 확인한다.
6. IMU 센서 연결 상태와 초기 roll, pitch 값을 확인한다.
7. 협동로봇 원점, TCP, 안전 영역을 확인한다.
8. 초음파 검사기 설정값과 프로브 상태를 확인한다.
9. 검사 계획 ID와 작업자 정보를 등록한다.

## 검사 실행 절차

| 단계 | 작업 | 확인 사항 |
| --- | --- | --- |
| 1 | 검사 계획 선택 | 대상, 위치, 검사 조건 |
| 2 | AMR 수동 이동 | 작업자가 리모컨으로 목적지까지 이동 |
| 3 | 기준 위치 확인 | 소형원자로 또는 기준 구조물 상대 위치 확인 |
| 4 | 아웃트리거 전개 | 접지 상태, 전개 완료 |
| 5 | IMU 수평 확인 | roll, pitch 허용 범위 확인 |
| 6 | 아웃트리거 수평 보정 | 수평 보정 완료, 안정화 확인 |
| 7 | 리프트 상승/하강 | 목표 높이, 리미트 상태 |
| 8 | 로봇 접근 | TCP 자세, 안전 속도 |
| 9 | 프로브 접촉 | 접촉력, 커플런트 상태 |
| 10 | UT 데이터 취득 | 신호 품질, 파일 저장 |
| 11 | 로봇 후퇴 | 안전 위치 도달, 프로브 분리 |
| 12 | 다음 위치 이동 준비 | 아웃트리거 회수 또는 이동 가능 상태 |
| 13 | AMR 자동 원주 이동 | 다음 검사 위치 도달 |
| 14 | 반복 검사 | 수평 보정부터 반복 |
| 15 | 작업 종료 | 로그 저장, 장비 복귀 |

## 검사 후 정리

- 검사 데이터 파일 저장 위치 확인
- 작업 로그와 데이터 파일 매칭 확인
- 검사 위치별 AMR 위치, IMU 수평 값, 아웃트리거 보정 결과 확인
- 이상 알람 및 중단 이력 확인
- 프로브 상태 및 소모품 상태 기록
- 필요 시 재검사 또는 수동 검토 요청

## 예외 상황

| 상황 | 대응 |
| --- | --- |
| AMR 수동 이동 중 장애물 발생 | 작업자 수동 정지, 주변 확인 |
| 기준 위치 인식 실패 | 자동 검사 시작 금지, 기준점 재확인 |
| AMR 위치 오차 초과 | 이동 중지, 재정렬 또는 수동 확인 |
| 아웃트리거 전개 실패 | 협동로봇 검사 금지, 접지 상태 확인 |
| IMU 수평 오차 초과 | 검사 금지, 아웃트리거 재보정 |
| 수평 보정 반복 실패 | 작업자 확인, 지면 상태 및 장비 상태 점검 |
| 리프트 리미트 감지 | 동작 중지, 높이 설정 확인 |
| 로봇 힘/토크 이상 | 즉시 정지, 접촉 상태 확인 |
| UT 신호 품질 저하 | 커플런트, 프로브, 접촉력 확인 |
| 데이터 저장 실패 | 검사 중지, 저장소 및 파일 권한 확인 |
| 비상정지 입력 | 모든 장비 안전 정지 후 원인 기록 |
