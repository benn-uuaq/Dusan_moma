# 안전 및 리스크 관리

## 안전 목표

- 작업자와 장비의 충돌 위험을 최소화한다.
- 협동로봇 검사 중 AMR 본체가 움직이거나 기울어지는 상황을 방지한다.
- 프로브, 검사 대상, 로봇의 과도한 접촉력을 방지한다.
- 오류 발생 시 시스템이 안전 상태로 전환되도록 한다.
- 검사 데이터 손실과 오판 가능성을 줄인다.

## 주요 위험 요소

| ID | 위험 | 영향 | 대응 |
| --- | --- | --- | --- |
| R-001 | AMR 수동 이동 중 장애물 충돌 | 작업자 부상, 장비 손상 | 리모컨 저속 운행, 작업자 시야 확보, 비상정지 |
| R-002 | AMR 자동 원주 이동 중 위치 오차 | 검사 위치 오류, 충돌 | 기준 위치 확인, 속도 제한, 이동 전 로봇 후퇴 확인 |
| R-003 | 검사 중 아웃트리거 미전개 | 본체 흔들림, 로봇 경로 오차 | 아웃트리거 전개 인터락 |
| R-004 | 본체 수평 불량 | 프로브 접촉 불량, 검사 데이터 품질 저하 | IMU 확인, 아웃트리거 수평 보정 |
| R-005 | 아웃트리거 접지 불량 | 본체 불안정, 전도 위험 | 접지 상태 확인, 보정 실패 시 검사 금지 |
| R-006 | 리프트 오동작 | 로봇 불안정, 충돌 | 리미트 센서, 높이 범위 제한 |
| R-007 | 로봇 프로브 과접촉 | 검사 대상 손상, 프로브 파손 | 힘 제어, 접촉력 제한, 정지 조건 |
| R-008 | UT 신호 품질 저하 | 결함 미검출 | 신호 품질 기준, 재검사 절차 |
| R-009 | 데이터 저장 실패 | 추적성 손실 | 저장 확인, 백업, 오류 알람 |
| R-010 | 장비 통신 끊김 | 제어 불능 | 타임아웃, 안전 정지, 재연결 절차 |

## 안전 기능 요구

- 물리 비상정지 버튼
- 소프트웨어 비상정지 명령
- 수동 이동과 자동 검사 모드 구분
- 협동로봇 검사 중 AMR 주행 명령 차단
- 협동로봇 검사 중 아웃트리거 회수 명령 차단
- 아웃트리거 전개 상태 확인
- IMU 기반 roll, pitch 허용 범위 확인
- 아웃트리거 수평 보정 실패 시 검사 시작 금지
- 장비별 동작 가능 범위 제한
- 협동로봇 안전 속도 및 힘 제한
- AMR 주행 구역 제한
- 리프트 상하한 제한
- 오류 발생 시 장비별 정지 순서 정의

## 비상정지 후 절차

1. 모든 자동 명령 출력을 중단한다.
2. AMR, 리프트, 아웃트리거, 협동로봇, UT 검사기의 상태를 확인한다.
3. 작업자 안전과 주변 환경을 확인한다.
4. IMU 수평 상태와 본체 접지 상태를 확인한다.
5. 비상정지 원인을 작업 로그에 기록한다.
6. 재시작 가능 여부를 담당자가 승인한다.

## 검토 필요 기준

- 적용 가능한 산업안전 기준
- 협동로봇 안전 관련 기준
- 이동로봇 및 무인운반차 안전 기준
- 원전/SMR 관련 품질 및 문서 기준
- 초음파 비파괴 검사 절차 기준
