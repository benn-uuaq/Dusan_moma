## 주요 기술 요건

### 협동로봇

- 검사 대상 곡률에 적합하게 설정된 스캔 프로그램과 함께 공급
- 주사속도와 진행속도 독립 조절 가능
- 최대 주사속도 150 mm/s 이상
- IP65 보호 등급 준수
- UT 시스템과 절대좌표 또는 엔코더 데이터 실시간 통신 지원
- Shell 원주면 외 상면부 검사 가능 구조
- 주사 중첩 범위 설정 기능 포함
- 로봇 본체, Controller, Teach Pendant, 전용 스캔 프로그램 포함

### 구동체 AGV

- 실외용 4륜 구동
- 바퀴 직경 200 mm 이상, 고무 재질, 충격 최소화 설계
- 검사 대상 제품 곡률을 따라 지정 각도와 위치로 자동 이동
- 이격 거리 유지 기능 및 위치 정보 제공
- 라이다 또는 근접 센서 탑재
- 설정 거리 이내 사물 접근 시 작동 일시정지
- 아웃트리거를 통한 고정 및 수평 조정
- 크레인 이동용 Eye Bolt 적용
- 검사 중/후 충전 가능한 이동형 충전장비 2개 포함
- 별도 리모컨 수동 운전 가능

### 리프트

- AGV 상단에 탑재하여 협동로봇 전체 수직 높낮이 제어
- 높이 조절 가능한 전동 스코프 타입
- 검사체 하단부부터 검사 시작 가능
- 교정룸 출입 높이 고려
- 수직 이동 및 스캔 중 흔들림 없는 안정 구동
- 케이블 및 접촉매질 공급 호스 간섭 없는 구조
- 수직 이동량 실시간 측정 및 데이터 제공

## 유지보수 및 보안 조건

- 하자 보증 기간은 납품 후 1년
- 문제 발생 시 1시간 이내 유선 응답, 4시간 이내 현장 착수 가능한 담당 기술자 지정
- 보증 만료 15일 전 점검 후 결과보고서 제출
- 비상연락 체계 문서 제출
- 기술 정보는 대외비이며 제3자 공개 불가
- 계약 체결 시 NDA 별도 체결
- 개인 컴퓨터의 이로운솔루션 및 두산에너빌리티 내부 네트워크 접속 불가
- 설계 및 개념 변경 시 이로운솔루션과 사전 서면 협의
- 안전인증 취득 비용은 3S Robotics 부담
- 부품은 가능한 상용품으로 구성하고 분해/조립 필요 공구 일체 제공
