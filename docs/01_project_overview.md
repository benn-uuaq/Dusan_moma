# 프로젝트 개요

## 목적

리프트가 장착된 AMR, 협동로봇, 초음파 검사기를 통합하여 소형 원자로(SMR) 관련 설비의 비파괴 검사를 자동화한다.

## 배경

SMR 설비는 높은 안전성과 품질 관리가 요구된다. 반복 검사, 접근성 제한, 작업자 안전, 검사 데이터 추적성 확보를 위해 이동형 자동 검사 시스템이 필요하다.

## 범위

### 포함

- AMR 기반 검사 위치 이동
- 리프트를 통한 검사 높이 보정
- 협동로봇 기반 초음파 프로브 제어
- 초음파 검사 데이터 취득 및 저장
- 검사 절차, 결과, 장비 상태의 문서화

### 제외 또는 추후 검토

- 방사선 환경 인증
- 원전 규제기관 제출용 최종 인증 문서
- 초음파 결함 자동 판정 AI의 정식 검증
- 실제 원자로 현장 투입 절차

## 주요 이해관계자

| 구분 | 역할 |
| --- | --- |
| 프로젝트 총괄 | 일정, 예산, 산출물 관리 |
| 기계/로봇 담당 | AMR, 리프트, 협동로봇 통합 |
| 검사 담당 | UT 검사 조건, 기준, 결과 검토 |
| 소프트웨어 담당 | 제어, 데이터, UI, 연동 프로그램 개발 |
| 안전 담당 | 위험성 평가, 안전 절차 검토 |

## 주요 산출물

- 시스템 구성 문서
- 요구사항 정의서
- 검사 운영 절차서
- 소프트웨어 설계 및 개발 산출물
- 테스트 계획 및 결과 보고서
- 검사 데이터 관리 기준
